L0 · 性能目标

性能目标层

所有设计参数的终点与起点 · 反向驱动 L1 设计窗口
⚡
能量密度
▶
Wh/kg = Q(mAh/g) × V_avg / 1000
Wh/L = Q × V_avg × ρ_electrode
// 提升路径：↑压实密度 + ↑活性物质比例 + ↑涂布量
↑压实密度
→
体积能量密度提升，但需平衡孔隙率下降导致的倍率损失
↑涂布量
→
面容量↑，但Li⁺扩散路径变长，厚电极需梯度孔隙率补偿

🔥
功率密度 / 倍率
▶
ℹ️
倍率性能由离子传输和电子传输共同决定，厚电极中离子传输通常是瓶颈。
孔隙率 ε
→
D_eff = D₀·ε/τ，孔隙率越高，离子有效扩散系数越大
曲折度 τ
→
τ↑ 则 D_eff↓，过度压延会增大曲折度
导电剂分布
→
电子传导网络均匀性影响高倍率下的极化分布

L1 · 微观结构

微观结构参数

孔隙率 · 压实密度 · 曲折度 · 膜片电阻
🕳️
孔隙率 ε
▶
ε = 1 − ρ_electrode / ρ_theoretical
D_eff = D₀ · ε / τ
// D₀: 电解液本体扩散系数；τ: 曲折度（典型值 1.5~4）
电极类型设计窗口优化方向
正极 NCM/NCA25~35%高能量取下限；高功率取上限
正极 LFP30~40%LFP离子扩散慢，需更高孔隙率
负极 石墨20~32%过低易析锂；过高浪费体积
负极 硅碳35~50%需为膨胀预留空间
🔗
制造关联：孔隙率由压延辊压参数决定。目标孔隙率 → 反推压实密度 → 确定辊缝设定值与线压力。
📝 笔记
🧱
压实密度 ρ
▶
ρ = m_coating / (A × t_coating)
// 与孔隙率呈反比，两者不独立，需联合设计
材料典型压实密度上限约束
NCM622/8113.3~3.6 g/cm³颗粒破碎风险↑
LFP2.2~2.5 g/cm³导电剂网络断裂
石墨1.55~1.65 g/cm³层间应力开裂
硅碳1.2~1.5 g/cm³膨胀预留空间
📝 笔记
〰️
膜片电阻 / 内阻组成
▶
📐
全电池内阻 = 电子阻抗 + 离子阻抗 + 界面阻抗 + 接触阻抗
电子阻抗
→
导电剂含量、分散均匀性、压实密度决定
离子阻抗
→
孔隙率、曲折度、电解液浸润性决定（EIS Warburg区域）
界面阻抗
→
SEI/CEI膜阻抗，EIS中频半圆，随循环增长
接触阻抗
→
极耳焊接质量、集流体接触，制造工艺相关
判定准则（全电池，室温，1C）:
DCR_norm < 2 mΩ·Ah → 良好
首圈 CE > 99.5% (正极) → 达标

➕
正极配方设计
▶
组分典型比例性能影响
活性物质 (AM)94~97 wt%↑能量密度；过高加工性变差
导电剂 (CB/CNT)1~3 wt%↑电子导电；过多占体积
粘结剂 (PVDF)1~3 wt%剥离强度；过少脱粉
浆料粘度
→
影响涂布均匀性，通常 3000~8000 mPa·s（刮刀涂布）
固含量
→
影响干燥速率和涂层结构，过高易出现龟裂
📝 笔记
➖
负极配方设计
▶
组分典型比例备注
石墨 (AM)95~97 wt%水系浆料，成本低
导电剂0.5~1.5 wt%石墨本身导电性尚可
CMC（增稠剂）1~1.5 wt%控制流变，影响涂布质量

L1 · 尺寸链

尺寸链与公差设计

Mean值 · RSS公差叠加 · Cpk要求 · N/P比 · Over Hang
📐
叠芯厚度尺寸链
▶
T_cell = N × (t_正极 + t_隔膜 + t_负极) + t_包装

t_极片 = t_箔材 + t_正面涂层 + t_背面涂层
t_涂层 = f(涂布量, 压实密度)

// RSS 统计公差叠加（优于最差情况法）：
σ_total = √(Σ σᵢ²)
T_total = ±3σ_total → 99.73% 置信区间
误差来源典型公差 (±μm)控制手段
涂布均匀性±2~5张力控制、浆料粘度稳定
压延回弹±1~3辊压速度、温度、材料回弹系数
隔膜厚度±1~2来料检验规格
铝/铜箔±1~2供应商 Cpk 要求 ≥ 1.33
📌
公差分配原则：按工艺能力（Cpk ≥ 1.33）反推允许公差，而非均摊。能力强的工序承担更紧的公差。
📝 笔记
📏
Over Hang 设计
▶
⚠️
Over Hang (OH) = 负极尺寸超出正极的单侧距离，是防析锂的核心安全参数。
OH = (W_负极 − W_正极) / 2

OH_min = f(极片对齐公差 + 膨胀量 + 安全裕度)
OH_max ← 受能量密度损失限制
// 典型设计范围：0.5~2.0 mm（液态电池）
AC / SA OH
→
顶边(AC)通常 > 侧边(SA)，顶部为析锂高风险区
OH 公差
→
由极片裁切精度 + 叠片对齐精度叠加决定（纳入尺寸链）
📝 笔记
⚖️
N/P 比设计
▶
N/P = Q_负极面容量 / Q_正极面容量
Q = 涂布量(mg/cm²) × AM比例 × 克容量(mAh/g)

// 设计目标（液态锂离子）：
1.05 ≤ N/P ≤ 1.15
N/P < 1.0 → 析锂风险
N/P > 1.2 → 能量密度损失 + 首圈 CE 影响
🔗
N/P比是连接正负极设计的核心纽带，需同时考虑面容量匹配与首效不可逆容量补偿。

压延工艺关联
▶

L2 · 梯度涂布

梯度 / 多层涂布设计

孔隙率梯度 · 动力学优化 · 厚电极设计
📊
梯度孔隙率设计原理
▶

底层（靠近集流体）

低孔隙率 20~25%
✅ 高压实密度
✅ 强电子导电网络
✅ 与集流体结合强
⚠️ 离子传输受限
↕梯度

顶层（靠近隔膜）

高孔隙率 35~45%
✅ Li⁺快速进入
✅ 电解液充分浸润
✅ 低倍率极化
⚠️ 体积能量密度稍低
📈
设计收益：相比均匀孔隙率电极，梯度设计可在相同能量密度下提升约 15~30% 倍率性能。电极厚度 >100 μm 时效果更显著。
层数设计参数L3测试验证方法
双层底/顶层孔隙率比 = 0.6~0.75GITT扩散系数 vs. SOC 曲线验证
三层+线性或抛物线梯度EIS频率扫描区分各层阻抗贡献
成分梯度底层高导电剂，顶层高AM截面SEM + EDS元素分布

L3 · 基础测试

基础电化学测试

GCPL · 倍率 · 库仑效率 · 循环稳定性
📈
恒流充放电 (GCPL)
▶
GCPL 标准测试规范
化成协议
0.05C → 0.1C → 0.2C 各1~2圈
定容条件
0.1C 或 0.2C，CC-CV，截止电流 0.05C
关键输出
首圈CE、可逆容量、平台电压、极化量
全电池注意
容量以限容端（通常正极）计算
CE = Q_放电 / Q_充电 × 100%
极化 ΔV = V_充电平台 − V_放电平台
// ΔV > 200mV @ 0.1C → 动力学问题，需查 EIS
📝 笔记
⚡
倍率性能测试
▶
测试序列
0.1C → 0.2C → 0.5C → 1C → 2C → 5C → 回0.1C
判定标准
5C/0.1C 容量保持率 > 80% → 良好倍率
L1关联
倍率衰退 → 检查孔隙率、曲折度（用GITT验证D_Li）
📝 笔记
🔄
循环稳定性
▶
标准条件
1C/1C 充放，室温
参比圈
每50圈插入一次0.1C，剥离动力学与热力学劣化
诊断节点
每50~100圈做EIS + dQ/dV，追踪失效演化
💡
插入参比圈是区分「动力学劣化」与「热力学容量损失」的关键操作，不可省略。

L3 · 动力学

EIS · GITT 动力学表征

阻抗分解 · 扩散系数 · 界面演化 · 活化能
〰️
电化学阻抗谱 (EIS)
▶
EIS 测试规范
频率范围
100 kHz ~ 10 mHz（宽频）；界面分析选 1 Hz~10 mHz
扰动幅值
5~10 mV（保持线性响应）
测试前处理
静置 OCV ≥ 2h；推荐多SOC点（0%, 50%, 100%）
温度依赖
−20°C, 0°C, 25°C, 45°C 对比，提取活化能 Eₐ
Nyquist 区域对应物理过程关联 L1 参数
高频截距 Rₑ欧姆内阻（电解液+极耳+集流体）电解液电导率、极耳设计
高频半圆SEI / CEI 膜阻抗 R_SEI界面膜厚度、化成工艺
中频半圆电荷转移阻抗 R_ct活性材料表面积、孔隙率
低频斜线Warburg 固相扩散Li⁺在活性材料中的扩散
低频尾/圆固态扩散积累厚电极、梯度结构敏感
等效电路（典型）:
R_ohm + (R_SEI // CPE_SEI) + (R_ct // CPE_dl) + W
// CPE: 常相位元件（非理想电容）；W: Warburg扩散元件
// 循环诊断：ΔR_SEI / ΔR_ct 比值变化 → 判断主导失效机制
📝 笔记
📡
间歇滴定技术 (GITT)
▶
GITT 测试规范
脉冲条件
0.05~0.1C，持续 10~30 min
弛豫时间
30~120 min（直至 dV/dt < 0.1 mV/min）
SOC分辨率
每步 5% SOC，覆盖 0~100%
D_Li⁺ = (4/π) × (m_B · V_m / M_B / A)² × (ΔE_s / ΔE_t)²
// ΔE_s: 稳态电压变化；ΔE_t: 脉冲期间电压变化
// 适用条件：短脉冲内满足 √t 线性关系
🔗
与梯度设计联动：梯度电极中不同SOC下的D_Li⁺曲线形状与均匀电极有差异，可用于验证梯度设计的实际动力学效果。

L3 · 增量分析

dQ/dV · 增量容量分析 (ICA)

相变追踪 · 容量衰退归因 · 无损全电池诊断
📉
dQ/dV 增量容量分析
▶
ICA 测试规范
充放电倍率
≤ 0.05C（准静态）获得清晰峰形；0.1C 为工程折中
数据采样
间隔 ≤ 1 mV 或 ≤ 10 s，过稀则峰形失真
平滑处理
Savitzky-Golay 滤波（窗口 15~25点），保留峰位精度
峰变化特征物理含义关联失效模式
峰面积减小对应相变容量损失活性物质损失 (LAM)
峰位左移（放电）极化增大阻抗增长、动力学劣化
正负极峰错位容量不匹配活性锂损失 (LLI)
峰展宽电化学不均匀性局部SOC分布不均
新峰出现新相生成过放深放、副反应
dQ/dV = dQ/dt ÷ dV/dt

// NCM正极 + 石墨负极 全电池峰识别：
~3.45V 峰 → 石墨 Stage III→II 相变
